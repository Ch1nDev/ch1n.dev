🔧 Setup — add your UptimeRobot API key
01 Sign up free at uptimerobot.com and add your sites/IPs as monitors.
02 Go to My Settings → API Settings and copy your Read-Only API Key (starts with ur).
03 Because UptimeRobot's API doesn't support CORS, you need a Cloudflare Worker proxy. Deploy status-worker.js (included below) to a Worker and set your key as a Secret named UPTIMEROBOT_KEY. Point it at e.g. api.status.chinberclart.dev.
04 Replace https://api.chinberclart.dev at the top of this file's script with your Worker URL. The setup card disappears automatically.
